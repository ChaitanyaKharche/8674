PROJECT OVERVIEW
A comprehensive curriculum analysis system that transforms raw course data into optimized academic plans.

DATA PROCESSING PIPELINE:
1. SCRAPING: Extracts course information from university catalogs and websites
2. GRAPH CONSTRUCTION: Builds prerequisite relationship graphs from raw data
3. ANALYSIS: Validates curriculum structure and identifies compliance issues
4. OPTIMIZATION: Generates optimal term-by-term course schedules
5. VISUALIZATION: Provides interactive exploration of course relationships

KEY OUTPUTS: Curriculum graphs, optimized schedules, analysis reports, interactive visualizations

SYSTEM ARCHITECTURE AND DATA FLOW
```mermaid
flowchart TD
    A[neu_scraper.py<br/>Data Extraction] -->|raw course data<br/>JSON responses| B[curriculum_analyzer.py<br/>Graph Analysis]
    B -->|cleaned graph data<br/>validated structure| C[inspect_graph.py<br/>Diagnostics]
    C -->|issue reports<br/>fix suggestions| D[curriculum_optimizer.py<br/>Scheduling]
    D -->|course schedules<br/>constraint solutions| E[agentic_optimizer.py<br/>AI Enhancement]
    E -->|optimized plans<br/>AI suggestions| F[interactive_visualizer.py<br/>Visualization]
    F -->|interactive graphs<br/>user exploration| G[streamlit_app.py<br/>Web Interface]
    C -.->|feedback for fixes| B
    D -.->|constraint updates| E
```
